# Contributing to WayFind

Thanks for helping improve WayFind.

## Development

1. Install Node.js 18 or newer.
2. Fork the repository or create a feature branch.
3. Run `npm start` and open http://localhost:3000.
4. Run `npm run check` before committing.
5. Keep changes focused and test desktop and mobile layouts.

## Pull requests

- Explain the user problem and the change.
- Include screenshots for meaningful UI changes.
- Avoid committing credentials, personal location data, or generated build folders.
- Keep visible OpenStreetMap attribution.
- Check the terms and usage limits of public map, geocoding, and routing services.
